# rifa

Aplicación local para el sorteo anual de la rifa Rett (tiras 1–1000).

Es un único fichero `index.html` sin dependencias: ábrelo en Chrome, Edge o Firefox. Los datos se guardan en el `localStorage` del navegador y se pueden exportar/importar como JSON.

Instrucciones de uso en [`LEEME.txt`](LEEME.txt).
